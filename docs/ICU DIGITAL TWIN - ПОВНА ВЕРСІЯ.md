## 📚 НАВЧАЛЬНІ ДАНІ ДЛЯ ВАЛІДАЦІЇ

### Датасети в комплекті:

```
cardiac_training_data.csv       - 1000 пацієнтів
abdominal_training_data.csv     - 1000 пацієнтів
vascular_training_data.csv      - 1000 пацієнтів
orthopedic_training_data.csv    - 1000 пацієнтів
thoracic_training_data.csv      - 1000 пацієнтів
```

### Структура CSV:

**Загальні поля (всі типи):**
- age, weight, height, bmi
- creatinine, hemoglobin, glucose
- diabetes, hypertension, copd, smoking
- ckd_stage, asa_class
- surgery_duration

**Специфічні поля:**
- **Cardiac:** ejection_fraction, ihd, cpb_duration, surgery_cabg, surgery_valve
- **Abdominal:** albumin, emergency, laparoscopic, oncology
- **Vascular:** peripheral_artery_disease, anticoagulants, emergency, critical_limb_ischemia
- **Orthopedic:** joint_replacement, trauma, anticoagulant_prophylaxis
- **Thoracic:** fev1_percent, oncology, vats

**Ускладнення (колонки 0/1):**
- aki, delirium, respiratory, infection
- + специфічні для кожного типу
