## 🚀 ШВИДКИЙ СТАРТ

### КРОК 1: Розпакувати архів

```bash
unzip ICU_Digital_Twin_Full_Package.zip
cd ICU_Digital_Twin_Full_Package
```

### КРОК 2: Встановити залежності

**Windows:**
```powershell
pip install streamlit pandas numpy scikit-learn plotly joblib
```

**Linux/Mac:**
```bash
pip3 install streamlit pandas numpy scikit-learn plotly joblib
```

### КРОК 3: Запустити додаток

**Windows:**
```powershell
python -m streamlit run streamlit_app_full.py
```

**Linux/Mac:**
```bash
python3 -m streamlit run streamlit_app_full.py
```

### КРОК 4: Відкрити браузер

Автоматично відкриється `http://localhost:8501`

## 💡 ТИПОВІ СЦЕНАРІЇ ВИКОРИСТАННЯ

### Сценарій 1: Тестування додатку (5 хвилин)

1. Розпакувати архів
2. Запустити `streamlit_app_full.py`
3. Обрати тип операції
4. Ввести тестові дані
5. Отримати прогноз

### Сценарій 2: Майстер-клас (90 хвилин)

1. Запустити у Google Colab (інструкція в `ІНСТРУКЦІЯ_Google_Colab.md`)
2. Отримати публічний URL
3. Роздати URL учасникам
4. Провести за планом (`План_майстер-класу_90хв.md`)
5. Роздати кейси (`Тестові_кейси_для_майстер-класу.md`)

### Сценарій 3: Валідація на власних даних (1-2 години)

1. Підготувати свої дані у форматі CSV
2. Завантажити модель (наприклад, `model_cardiac_af.pkl`)
3. Використати код з `ІНСТРУКЦІЯ_Повна_версія.md` (розділ "Валідація")
4. Порівняти AUC з нашими метриками
