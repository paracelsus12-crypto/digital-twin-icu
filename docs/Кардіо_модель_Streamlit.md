## 🖥️ ВАРІАНТ 1: ЛОКАЛЬНИЙ ЗАПУСК (НА ВАШОМУ КОМП'ЮТЕРІ)

**Windows:**
1. Завантажити з https://www.python.org/downloads/
2. ✅ Важливо: Поставити галочку "Add Python to PATH"
3. Встановити

**macOS:**
```bash

```

**Linux (Ubuntu):**
```bash
sudo apt update

```

### Крок 2: Встановити бібліотеки

Відкрийте командний рядок (Terminal) та виконайте:

```bash

```

### Крок 3: Запустити додаток

```bash

streamlit run streamlit_app.py
```

### Крок 4: Відкрити в браузері

Автоматично відкриється: **http://localhost:8501**

Або вручну відкрийте цей URL у браузері.

## ☁️ ВАРІАНТ 2: STREAMLIT CLOUD (БЕЗКОШТОВНИЙ ХОСТИНГ)

### Переваги:
- ✅ Безкоштовно
- ✅ Не потрібен власний сервер
- ✅ Доступно з будь-якого пристрою
- ✅ Автоматичні оновлення

### Інструкція:

#### 1. Створити GitHub репозиторій

1. Зареєструватись на https://github.com (якщо немає акаунту)
2. Натиснути "New repository"
3. Назва: `icu-digital-twin`
4. Зробити Public
5. Створити

#### 2. Завантажити файли на GitHub

**Варіант А: Через веб-інтерфейс**
1. Натиснути "Add file" → "Upload files"
2. Перетягнути всі файли:
   - streamlit_app.py
   - model_*.pkl (5 файлів)
   - icu_training_data.csv
   - model_metrics.json
3. Натиснути "Commit changes"

**Варіант Б: Через Git (якщо вмієте)**
```bash
git init
git add .
git commit -m "ICU Digital Twin app"
git remote add origin https://github.com/YOUR_USERNAME/icu-digital-twin.git
git push -u origin main
```

#### 3. Створити requirements.txt

У GitHub репозиторії створіть файл `requirements.txt`:

```
streamlit==1.31.0
pandas==2.2.0
numpy==1.26.0
scikit-learn==1.4.0
joblib==1.3.2
plotly==5.18.0
```

#### 4. Задеплоїти на Streamlit Cloud

1. Перейти на https://share.streamlit.io/
2. Натиснути "New app"
3. Підключити GitHub акаунт
4. Вибрати репозиторій: `icu-digital-twin`
5. Main file path: `streamlit_app.py`
6. Натиснути "Deploy"

⏱️ Деплой займе 3-5 хвилин

#### 5. Отримати URL

Після деплою ви отримаєте URL:
```
https://YOUR_USERNAME-icu-digital-twin.streamlit.app
```

Цей URL можна використовувати на майстер-класі!

## 🆘 TROUBLESHOOTING

### Проблема: "ModuleNotFoundError: No module named 'streamlit'"
**Рішення:**
```bash
pip install streamlit
```

### Проблема: "FileNotFoundError: model_af.pkl"
**Рішення:**
- Переконайтесь, що всі .pkl файли в тій же папці, що й streamlit_app.py
- Або змініть шляхи в коді

### Проблема: Streamlit не запускається
**Рішення:**
```bash
# Перевірити Python
python --version  # Має бути 3.8+

# Перевірити Streamlit
streamlit --version

# Переінсталювати
pip uninstall streamlit
pip install streamlit
```

### Проблема: Порт 8501 зайнятий
**Рішення:**
```bash
streamlit run streamlit_app.py --server.port 8502
```
