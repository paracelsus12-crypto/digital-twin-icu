## 💡 ПІДКАЗКИ ДЛЯ ІНТЕРПРЕТАЦІЇ

### Як читати відсотки:

**🔴 Високий ризик (>60%):**
- Обов'язкові превентивні заходи
- Інформувати команду
- Готовність до лікування
- Моніторинг посилений

**🟡 Помірний ризик (30-60%):**
- Підвищена настороженість
- Готовність до втручання
- Стандартний моніторинг +

**🟢 Низький ризик (<30%):**
- Стандартний протокол
- Рутинний моніторинг

### Що робити з результатами:

1. **Обрати ТОП-2 ризики** (найвищі %)
2. **Прочитати рекомендації** для цих ризиків
3. **Імплементувати** превентивні заходи
4. **Інформувати** команду про ризики
5. **Посилити** моніторинг відповідних параметрів
