### ✅ ВАРІАНТ 2: СТВОРИТИ УНІВЕРСАЛЬНУ BASELINE МОДЕЛЬ

**Суть:**
Додати спрощену модель для **всіх типів операцій** на основі загальних ускладнень.

**Які ускладнення працюють для ВСІХ операцій:**
1. ✅ Гостре пошкодження нирок (AKI)
2. ✅ Респіраторні ускладнення (ARDS, пневмонія)
3. ✅ Делірій
4. ✅ Інфекційні ускладнення
5. ✅ Тромбоемболічні ускладнення (ТЕЛЬ, ТГВ)

**Кардіоспецифічні (залишити тільки для кардіо):**
- Фібриляція передсердь
- Низький серцевий викид
- Інсульт (специфічний для кардіо/судинної)

**Технічна реалізація:**

```python
# При введенні даних - додати поле:
surgery_type = st.selectbox("Тип операції", [
    "Кардіохірургія (АКШ, клапани)",
    "Абдомінальна хірургія",
    "Судинна хірургія",
    "Ортопедія/травматологія",
    "Торакальна хірургія",
    "Інше"
])

# Якщо кардіохірургія:
if surgery_type == "Кардіохірургія":
    complications = ['af', 'aki', 'lco', 'stroke', 'bleeding']
else:
    # Універсальні ускладнення для всіх
    complications = ['aki', 'respiratory', 'delirium', 'infection', 'te']
```

**Як натренувати універсальну модель:**
1. Використати дані з BUS-17 (якщо є доступ)
2. Синтезувати дані на основі літератури (STS Database, NSQIP)
3. Використати трансферне навчання від кардіо-моделі

**Приклад спрощених моделей:**

```python
def predict_aki_universal(age, creatinine, diabetes, surgery_duration):
    """Універсальна модель AKI для всіх операцій"""
    risk = 10
    if age > 65: risk += 10
    if creatinine > 120: risk += 20
    if diabetes: risk += 15
    if surgery_duration > 180: risk += 10
    return min(risk, 95)

def predict_delirium(age, cognitive_baseline, surgery_duration):
    """Модель делірію"""
    risk = 5
    if age > 70: risk += 25
    if age > 80: risk += 15
    if cognitive_baseline == "MCI": risk += 20
    if surgery_duration > 240: risk += 15
    return min(risk, 85)
```

#### Переваги:
- ✅ 100% учасників можуть використати
- ✅ Реально корисно для всіх
- ✅ Більша зацікавленість

#### Недоліки:
- ⚠️ Потрібно 2-3 дні розробки
- ⚠️ Точність буде нижча (60-70% замість 75-85%)
- ⚠️ Потрібні додаткові дані для тренування
