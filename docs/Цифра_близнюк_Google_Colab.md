### КРОК 5: Налаштувати ngrok (для публічного URL)

**🔑 Спочатку отримайте токен ngrok:**

1. Перейдіть на: **https://dashboard.ngrok.com/signup**
2. Зареєструйтесь (безкоштовно, через Google/GitHub)
3. Після реєстрації перейдіть на: **https://dashboard.ngrok.com/get-started/your-authtoken**
4. **Скопіюйте** ваш authtoken (виглядає як: `2aB3cD4eF5gH6iJ...`)

**📝 Створіть третій блок і вставте:**

```python
# Налаштування ngrok
import getpass
from pyngrok import ngrok

print("🔑 Вставте ваш ngrok authtoken нижче:")
ngrok_token = getpass.getpass("Authtoken: ")

!ngrok authtoken {ngrok_token}

print("\n✅ Ngrok налаштовано!")
```

**▶️ Запустіть**

Вставте ваш authtoken і натисніть Enter.

### КРОК 6: Запустити Streamlit!

## 🔄 АЛЬТЕРНАТИВНИЙ МЕТОД (БЕЗ NGROK)

Якщо не хочете реєструватись на ngrok, можна використати **localtunnel**:

**📝 Замість кроків 5-6 використайте:**

```python

# Встановлення localtunnel
!npm install -g localtunnel
```

- URL може змінюватись при кожному запуску

## 🆘 TROUBLESHOOTING

### Проблема: "ERROR: Could not find ngrok"
**Рішення:** 
```python
!pip install pyngrok
```

### Проблема: "ngrok authtoken is not set"
**Рішення:** Перевірте, чи правильно вставили authtoken

### Проблема: "Streamlit not found"
**Рішення:**
```python
!pip install streamlit
```

### Проблема: "Port 8501 is already in use"
**Рішення:**
```python
# Використайте інший порт
subprocess.Popen(["streamlit", "run", "streamlit_app.py", "--server.port", "8502"])
public_url = ngrok.connect(8502)
```

### Проблема: Файли не завантажились
**Рішення:** 
- Перевірте розмір файлів (мають бути <10 MB кожен)
- Завантажуйте по одному файлу
- Перезапустіть блок завантаження

|----------|-------------------|--------------|
